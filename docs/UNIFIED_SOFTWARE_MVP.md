**Пока кандидат cloud/CI. На ПК владельца запуск не проверен: компьютер был выключен. Профиль и данные не перенесены, уборка не выполнялась.**

После отдельного безопасного обновления открыть основной `C:\projects\kz-home-web`, не временную копию. Фактические пути и используемую папку Web нужно подтвердить на ПК.

## Одна конфигурация PyCharm

Имя: **KZ Home — запуск**. Тип Python, **существующий WSL/Linux interpreter** с установленными зависимостями Core. Скрипт — существующий `kz-home-core/tools/durable_software.py`; рабочая папка — основной `kz-home-web`. Все три пути указывать в формате выбранного Linux-интерпретатора. Параметры:

```text
start --state <существующий согласованный профиль> --web-root <основная папка kz-home-web>
```

`start` повторно использует **тот же** профиль, БД и Web-порт. Не добавлять `init`, restore/upgrade, очистку или создание новых профилей в Before launch. После нажатия зелёной кнопки адрес появится в Run console; адрес не угадывать. Пользователь: `owner@example.test`; пароль смотреть **локально** в поле `password` существующего `profile.json`, не публиковать файл или снимок с паролем.

Native Windows Python не поддержан: launcher использует POSIX locks и Unix Docker socket. Если установленный PyCharm не поддерживает существующий WSL-интерпретатор, использовать его уже настроенный WSL-терминал, рабочая папка основной Web, и одну команду:

```bash
"$PYTHON" "$CORE/tools/durable_software.py" start --state "$PROFILE" --web-root "$PWD"
```

`PYTHON`, `CORE`, `PROFILE` один раз назначаются **после проверки фактических существующих путей**, не по примеру. На неизвестной установке эту конфигурацию нельзя называть проверенной. Не устанавливать WSL, плагины, Docker или зависимости автоматически. Подтверждённый CI проверяет тот же Python launcher и аргументы; не GUI PyCharm/Windows.

Остановить штатным Ctrl-C в терминале; данные сохраняются. Повторить ту же команду для повторного запуска. Поведение кнопки Stop в конкретной PyCharm-конфигурации нужно проверить на ПК отдельно, не заменять это остановкой Docker.

**Версии и одноразовое обновление с сохранением данных:** [SOFTWARE_UPGRADE.md](SOFTWARE_UPGRADE.md). Это Core + Web + программное MQTT-реле, не физическая ESP32 и не production. Приёмка: вход → комната → реле → ACK/state → избранное → обновление страницы. Скриншоты и exact SHA относятся к финальному отчёту, не к этой непроверенной конфигурации.
