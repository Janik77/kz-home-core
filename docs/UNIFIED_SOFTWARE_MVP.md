# Общая программная версия KZ Home

Кандидат, не заявление о готовности:
- Core runtime `fc232035f78c99171fd72ac82c78eb1b5bb657fa`.
- Web `31dd1029173af6c7ff4ed4e9bf0c80679c185b3b`.
- Tooling `5ac2045476ef9a7b772e908249044b1e5bccb080`, schema `0017_metadata_cas`.
- Отдельная ветка `integration/durable-wait-web31`, без merge в main.

**Единая инструкция:** [read-only preflight, backup, новое назначение, проверка и rollback](SOFTWARE_UPGRADE.md). Сейчас квалификация только в CI; действующий стенд владельца не изменять.

Состав: существующий React Web, FastAPI, PostgreSQL, MQTT TLS, программное реле; подтверждённые команды, сценарии и автоматизации, numeric thresholds, IANA-расписания и явные durable waits между подтверждёнными шагами. Старый `delay` не активируется.

Same-DB restart и restore новой копии различаются: в копии parked продолжения отменяются с `restore_invalidation`, чтобы не удвоить исполнительное намерение. Исходные данные, receipts и история сохраняются. Неизвестная отправленная команда никогда не повторяется автоматически.

Отдельные статусы приёмки: визуально проверено; работает с реальным Core/программным MQTT; проверено на физическом устройстве. Последнее не выполнялось. Адрес предпросмотра берётся из реально запущенного launcher, не выдумывается. Финальный отчёт обязан содержать exact integration SHA, CI и браузерные доказательства; этот документ их не заменяет.
